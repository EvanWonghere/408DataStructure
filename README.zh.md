# 408DataStructure——数据结构复习项目

[English Version](README.md)
---

此项目是一个基于 C++ 的数据结构学习项目，根据中国研究生入学考试中的 408 考纲内容进行分组、实现和例题练习。

## 项目目录结构

```bash
data-structures-cpp/
├── common/          # 全篇通用组件（时间测量、输出、简单的测试等）
├── chapters/        # 按章节分组的内容，每章为一个小工程
├── CMakeLists.txt   # 全局 CMake 配置
└── README.md        # 项目介绍
```

## 章节内容

* `data_structures/`: 根据本章纲要实现的数据结构
* `exercises/`: 练习题代码
* `examples/`: 数据结构的使用 demo
* `tests/`: 数据结构的测试代码
