# 408DataStructure -- Data Structures Review in C++

[中文版](README.zh.md)
---

This project is a C++-based practice and review of classic data structures, structured chapter-by-chapter based on the syllabus of "408" (the standard Chinese CS postgraduate entrance exam).

## Project Layout

```bash
data-structures-cpp/
├── common/          # Shared utilities (timing, output, simple testing, etc.)
├── chapters/        # One folder per chapter, each acting as an isolated project
├── CMakeLists.txt   # Root-level CMake config
└── README.md        # Project overview
```

## Chapter Contents

* `data_structures/`: Core data structures introduced in the chapter
* `exercises/`: Exercise implementations (often with `main()`)
* `examples/`: Usage demos of the data structures
* `tests/`: Test codes of the data structures
