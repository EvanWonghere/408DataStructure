# Chapter 2 -- Linear List

[中文版](README.zh.md)
---

The core focus of this chapter is the concept of "linear lists," which we categorize into two main types: `sequential storage structures` and `linked storage structures`. 

For sequential storage structures, we will explore two implementation methods: **static memory allocation** and **dynamic memory allocation.** 

As for linked storage structures, we will delve into the implementation of the following types of linked lists: singly linked lists, doubly linked lists, circular singly linked lists, circular doubly linked lists, and static linked lists.
